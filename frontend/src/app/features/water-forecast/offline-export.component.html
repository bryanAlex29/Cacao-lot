Cómo usar y proteger el archivo

El JSON contiene identificadores y lecturas privadas, sin claves ni contraseñas. Guárdalo en un archivo nuevo dentro de la carpeta .local del proyecto; no lo subas a GitHub ni sobrescribas otra entrada.

Evalúalo después con las herramientas offline de persistencia y regresión. La regresión necesita el entorno Python privado. Esta pantalla no ejecuta esas herramientas ni afirma precisión agrícola.
